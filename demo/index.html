AI detector plugin demo

Press the Check for AI writing button in the toolbar. The page replays a recorded answer from the AssetFeed detector for the sample text, so it works without an API key. Edited text needs a real key.

Sample text: the opening of Three Men in a Boat by Jerome K. Jerome (1889, public domain), followed by three paragraphs written by an AI model.

To check your own text, connect the plugin to an AssetFeed account. Free accounts include 500 credits per month, and one check uses 5 credits. Get an API key or see plans.
